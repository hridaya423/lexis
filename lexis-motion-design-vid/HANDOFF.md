# Lexis Ad — Handoff

**Current state: DONE.** Final deliverable is `lexis-ad-v9.mp4` — 15.0s, 1920×1080, 60 fps,
audio at −9.5 LUFS / −1 dBTP, ends on the Lexis logo. Committed, tagged `lexis-ad-v9`.

## The ask

A fast-paced ~15s brand ad for Lexis (natural-language terminal assistant,
https://lexis.hridya.tech), built fully from scratch in this folder. Direction evolved
through user feedback toward "a16z techno-optimism": archival computing history accelerating
to the present, the punchline that we still memorize terminal syntax, then Lexis as the
answer. No beige, painted/cellular graphic treatments over images, ends on the logo.

## The concept

Old terminals are green phosphor on black; Lexis is black ink on lime paper. The whole
history half plays *on a CRT* (curvature, scanlines, glow, flicker, gate weave, rolling
band); when Lexis arrives the screen powers off to a dot — which becomes the cursor — and
lime paper floods out. Everything (photos, years, headlines, commands, logo) is built from
one grid of square LCD cells so any element can morph into any other. One coral cursor block
ties it together.

Beat map (15s @ 60fps = 900 frames):

- 0–0.5s: cursor blinks, stretches, opens into first shot
- 0.5–2.65s: patent-drawings strobe (1868–1941) + accelerating archival montage,
  LCD year counter climbing, flash cuts, NASA countdown → Glenn → capsule
- 2.65–6.25s: "We reached / the moon." "We wired / the world." "We taught sand / to think."
  Copy flips letter-by-letter on LCD plates; strobing continues through 1969–1991 flipbook
  (Pong → IBM PC → Jobs/Mac → Hubble…); giant year races to 2026; people/celebration shots
  around Saturn V and bootprint
- 6.25–8.6s: Fludd 1617 "eye of imagination" engraving, memory panels replaced by flags
  (`tar -xzvf`, `chmod 755`) under "We still memorize" → slam on `tar -xzvf` → flag wall
  collapses → CRT power-off to dot → silence → paper flood
- 8.6–11.6s: three plain-English requests; cursor becomes coral 3D Return key, gets pressed;
  English letters fall into matching commands
- 11.6–15s: commands become "In your own words.", cursor backspaces it, types `lexis`
  logo, parks after it. Flare glints on the dot of the "i".

## Music (the hard part — read the feedback history)

The score is **generated by Python scripts**, not a found track. Current: `raw/score9.py`
→ `film/assets/score9.wav`. Engine: **Surge XT** (VST in `raw/plugins/`, driven from Python
via `pedalboard` + `scipy`) for synths, plus **VSCO-2 CE** orchestral/percussion samples
(CC0, in `raw/vsco/`) for the acoustic drums, plus real CC0 SFX (typewriter, teletype,
Return key, NASA Saturn roar).

Final musical shape (v9 = v8's arrangement, louder): ONE continuous intro motif
(D-pulse figure, root-root-fifth-octave on 16ths + tenor-drum pattern) drags through the
entire history half — no drop. Saturn V gets a soft boom, not a hit. Glide down into
D-minor "memorize" section, dissonant slam, tape-stop into silence. Lexis section is a
second build in the same language resolving to a full D-major hit on the logo.

**Feedback arc (important — don't regress):**

- v1–v2 custom synth score: "too flat, needs a16z swell/drop dynamics"
- v3 real-orchestra score: "too orchestral, not the a16z vibe"
- v4 Surge XT cinematic electronic: "middle sounds sloppy, want more drama/drums/mystery/epic"
- v5 tightened grid + acoustic drums + D-minor mystery arc: "2–5s beat is slop; intro is good; music has no feel"
- → diagnosis: drop broke every rule the intro followed (dance beat at wrong tempo, too many
  16th parts, 4 chords in 2.4s, melody spent early). Ideated 4 directions, rendered
  `v6-drop-sketches/` (A cinematic / B retro / C emotive / D minimal). **User picked A (cinematic),
  asked for MORE cinematic and more of the intro beat.**
- v6: intro figure carries the whole film → "middle still doesn't feel good"
- v7: **no drop at all — intro drags straight through history half** → "make the transitions smoother"
- v8: smoothed both seams (~2.6s Saturn, ~6.2s memorize); punchline loudness step 7.5→3.1 dB → approved
- v9: user said "make it louder everything" → mastered to −9.5 LUFS, lifted the quiet opening
  an extra ~5–6 dB, peak −1 dBTP. LRA now ~1.5 LU (heavily limited — deliberate per request).

**I could never hear the audio.** All choices were made on measurements (LUFS, LRA,
short-term loudness steps, spectral balance vs the a16z reference tracks, note-onset vs
beat-grid checks). User's ear approved v8/v9.

## Rebuild / iterate

```bash
cd film
npm run check                                  # REQUIRED after any .html edit
tools/final.sh                                 # full re-render (~10 min: 240fps → 60fps MB + CRT)
tools/final.sh assets/scoreN.wav out.mp4 --skip-render   # remux audio only (<1 min)
python3 ../raw/score9.py                       # regenerate the score (~30s)
```

## Gotchas (each one bit us)

- **HyperFrames Studio rewrites `index.html`** — never leave `preview --background` running
  while editing; stop it (`npx hyperframes preview --stop`).
- **Cell text misreads if sampled before Departure Mono loads** — raster setup is behind
  font-load completion; keep it that way.
- **GSAP timelines are thenables** — don't `return tl` inside promise chains; wrap it.
- **Deterministic only** — no `Date.now()`/`Math.random()` in the composition.
- **GitHub 100 MB file limit** — masters are ~70 MB at CRF 17 (`final.sh` CRF is env-tunable).
- **Disk** — `raw/video` holds ~1.6 GB of source reels; everything gitignored under `raw/`,
  `research/refs`, `film/renders` is re-downloadable. Drive has run near-full before; clean
  intermediates if a render fails on space.
- **Git scope** — commits were scoped to `lexis-motion-design-vid/` only. The user's unrelated
  work (`lexis/` policy/training, `.devin/goal/`) is dirty in the same repo — do NOT sweep it
  into film commits.
- **Audio caveat for the next person** — the score has only ever been validated by measurement,
  not by a human ear before delivery. If the user reports a new audio nit, timestamp + one
  word ("4s too busy") is the fastest fix loop.
